GitHub storage

Your products and photos are stored in a private GitHub repository that only you can access.

  1. On github.com create a private repository (for example food-data).
  2. Go to Settings › Developer settings › Fine-grained tokens › Generate new token.
  3. Under Repository access choose Only select repositories and pick that repo. Under Permissions › Repository set Contents to Read and write.
  4. Copy the token and paste it below.
